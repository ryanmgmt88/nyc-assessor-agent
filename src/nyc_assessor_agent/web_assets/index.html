Filing extension logic used by this tool
DOB NOW filings under the same construction project use the same parent job number plus an extension showing filing type and sequence. This page groups all records by parent job number. It treats -I# as initial, -S# as subsequent, and -P#/-A# as amendment/PAA-style records for cost tracking. Older/observed records may show amendment sequence as -A1; this page keeps it with the same parent job instead of counting it as a separate project.

DOB term fix: Job Type means NB, Alteration, ALT-CO, No Work, etc. Work Type means the actual trade/scope such as GC General Construction, MS Mechanical Systems, FN/FO Foundation, EW/EA Earthwork, ST Structural, PL Plumbing, etc.

Best cost tracking illustration

Use this flow to avoid double-counting PAAs. Parent job = valuation project. Filing extensions = revisions/additional scope. Separate approval-estimated cost from permit/fee cost.

1. ParcelStart with BBL and all associated BINs. Confirm condo/apportionment issues before valuation.
2. Parent JobStrip suffix: Q00657466-A1 -> Q00657466. Group all extensions together.
3. Filing TypeInitial/subsequent/PAA. PAA changes approved plans; subsequent adds separate scope/work type.
4. Approval CostTrack declared/estimated construction cost from approved filings and revisions.
5. Permit CostTrack permit/filing fees separately. Do not confuse DOB fees with physical improvement value.
Assessor rule of thumb: for progress assessment, use job scope, inspection/readiness, CO/TCO/LOC, and physical condition. Permit fees are an administrative cost signal, not the improvement value.
